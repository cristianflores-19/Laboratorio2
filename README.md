# Laboratorio2
## Preguntas
### 1. ¿Para qué crees que se usan los operadores lógicos en programación?
Desde mi punto de vista sirven para simplificar procesos en las lineas de código ya que nos permite tomar desiciones de manera eficiente.
### 2. ¿Por qué es importante declarar correctamente el tipo de dato de una variable?
Porque si no declaramos correctamente nuestras variables, será un código sucio y desordenado ya que si más adelante queremos
modificar nuestro código, no sabremos que es ni para que sirve cada variable.
## Enunciados
### Enunciado 1: Clasificación de edad
**¿Qué estructura usaría?**: Usaria  ``if-else``
**¿Por qué?**: La estructura if es ideal para programar cosas de este estilo ya que con el if y el else podemos hacer condicionales
que ayuden a saber en que clasificación de edad se encuentra el usuario.
### Enunciado 2: Día de la semana
**¿Qué estructura usaría?**: Usaria  ``Switch``
**¿Por qué?**: El switch es perfecta para estos casos ya que se le pide al usuario que ingrese un numero dentro de un rango ya especificado
y depende de lo que el usuario ingrese se mostrará un dia de la semana.
### Enunciado 3: Verificación de acceso
**¿Qué estructura usaría?**: Usaria  ``if-else``
**¿Por qué?**: Usaria este estructura porque esta nos permite hacer la condición de que si se cumple los datos que ingrese el usuario con
los datos ya preestablecidos se iniciará sesión, y también usando else if podemos hacer varias condicones.
