# Laboratorio2
## 1. ¿Para qué crees que se usan los operadores lógicos en programación?
Desde mi punto de vista sirven para simplificar procesos en las lineas de código ya que nos permite tomar desiciones de manera eficiente.
## 2. ¿Por qué es importante declarar correctamente el tipo de dato de una variable?
Porque si no declaramos correctamente nuestras variables, será un código sucio y desordenado ya que si más adelante queremos
modificar nuestro código, no sabremos que es ni para que sirve cada variable.
